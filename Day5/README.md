# Iris Classification

使用Scikit-learn 对 Iris 鸢尾花数据集进行分类

##学习内容

-使用 'load_iris()' 加载数据集
-理解特征 'X' 与标签 'y'
-使用 'train_test_split()' 划分训练集和测试集
-使用 Logistic Regression 训练分类模型
-使用 accuracy、classification report 和 confusion matrix 评价模型


##Dataset

Iris 数据集包含：

-150个样本
-4个特征
-3个类别


##Model

使用：

Logistic Regression


##Result

在 'random_state=42'、测试集比例为20%的情况下：

Accuracy=1.0
